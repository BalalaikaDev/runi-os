# BalalaikaDev GitHub profile — plan

Staging area for the `BalalaikaDev/BalalaikaDev` profile README. Move this folder
there once that repo exists (it doesn't yet, as of 2026-10-22).

## Decisions so far
- **Concept:** neon cyberpunk "SIGINT console". Signature piece is a radar scope whose
  blips are projects. **Not** classic green/grey radar — use the Runi Shell palette
  (bg `#06070f`, cyan `#18e0ff`, magenta `#ff2e97`, yellow `#fcee0a`, green `#00ff9c`).
- **Projects shown now:** `runi-os` and the `kindle-ai-export` reader fork. More later.
- **Must-have:** an auto-updating "what I'm working on" section, generated by a
  scheduled GitHub Action (no hosted server; README images must be public anyway).

## Build order
1. Banner/radar (`generate_radar.py`, prototype done) + bio + pinned repos with
   custom social-preview images.
2. **Activity generator** (scheduled Action): last commits / current focus written as a
   fake terminal session (`$ whoami`, `$ cat now.txt`, `$ tail -f activity.log`),
   rendered as a themed SVG and committed to the profile repo.
3. Make the radar data-driven: pull public repos from the GitHub API; bearing/range
   from e.g. language and recency; blip flares on recently pushed repos.
4. Extras: `<details>` easter eggs, a themed stats card, maybe an issue-driven game.

## Constraints
- No JS/CSS on GitHub — animation is SMIL/CSS inside the SVG only.
- No web fonts in README SVGs (fetched via GitHub's image proxy) — monospace stack.
- GitHub caches images; "live" means refreshed every few hours.
- Must read well at phone width.
